# `zaino-primitives`: Chain work is two types: `AbsoluteChainWork`, the cumulative work from genesis, and `SingleBlockWork`, one …

Chain work is two types: `AbsoluteChainWork`, the cumulative work from genesis, and `SingleBlockWork`, one block's contribution, with `genesis`, `accumulate` and `rollback` operations. Each work error is defined in the module that raises it.

**Migration:** Replace the single chain-work type with `AbsoluteChainWork` for totals and `SingleBlockWork` for one block's work.
