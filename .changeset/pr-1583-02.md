# `zaino-primitives`: `EncryptedCiphertext` is renamed `CompactCiphertext`, because it holds only the 52-byte compact prefix

`EncryptedCiphertext` is renamed `CompactCiphertext`, because it holds only the 52-byte compact prefix. It is a `[u8; 52]` behind an exact-length `try_new`.

**Migration:** Rename `EncryptedCiphertext` to `CompactCiphertext`, and construct it with `try_new` from exactly 52 bytes.
