# `zaino-sync`: First release

First release. The final path: `FinalFollower::new(chain, balancer, lookahead)` fetches every block up to the `VerifiedChain`'s final tip height, in order: a height the verified chain holds a header for by hash from any member, peers included (`fetch` / `check_block`), below it by height from trusted members (4 per batched `getblock` request; `fetch_at` / `check_block_at`: coinbase height only, the trusted member's body taken as is; a misanswer (`Misanswer::{WrongBlock, WrongHeight, Body}`) `report`ed and re-asked) onto one `IndexerDataSink<Block>`, from the lowest durable tip (`subscribe(kind, durable, queue)`). Each block must extend the block sent before it (`FollowError::Unlinked`) and each durable tip it reaches (`FollowError::Diverged`, naming the index). `fetch` / `check_block` fetch by hash against a verified header (the NFS's). `IndexerDataSink<T>` is a byte-bounded broadcast queue (all-or-nothing `send`, `shutdown`); `FeeSink` carries value-balance's fees to compact-block; the follower sends the block at the chain's final tip as `Step::Finalized`. Each writer runs its own loop: `Subscription::next_run` = one run of queued steps (`Run { blocks, finalized }`, to the queue's budget; `None` = `Shutdown`), folded in one `blocking` hop through `held(store, height)`, `assert_next` / `assert_run` (a fold's preconditions), `apply(store, changes)` (`Store::apply`, counted) and `commit(store)` (after a finalized run and at `Shutdown`; a failure panics naming the index and its directory); the store commits a full buffer by itself. `IndexPublisher` (`new(&store)`, `handle()`, `publish(&store)` after every hop) is the writer's end of its `IndexHandle`, what the rest of the daemon knows about one index (`view`, `tip`, `changed`). `SyncProgress` = the last height sent (`zaino_fetch_height`); `zaino_fetch_*_total` metrics; per writer run `zaino_index_run_seconds` + `zaino_index_write_seconds` `{index}` (`ran`; `apply` / `commit` return their store time; `METRIC_BUCKETS`); `compute` for CPU work on the rayon pool. `IndexerDataSink::new()` takes no name.
