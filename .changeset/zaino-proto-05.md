# `zaino-proto`: `GetStandardFee` rpc and `StandardFee` message

`GetStandardFee` rpc and `StandardFee` message (`feeZat`, `estimatorVersion`), vendored from lightwallet-protocol v0.6.0: the ZIP 317 marginal fee in zatoshis per logical action and the backend fee-estimator version, as reported by the backend's `getstandardfee` JSON-RPC.
