# `zaino-chain-head-service`: `ChainHeadAdvanceError::SourceUnavailable` carries the source's `FetchError` instead of a `String`, so …

`ChainHeadAdvanceError::SourceUnavailable` carries the source's `FetchError` instead of a `String`, so `Error::source()` returns the transport cause and its `FailureMode`. A rejected query stays under `InconsistentSource`, naming the query.

**Migration:** Match `SourceUnavailable(fetch_error)` and format the error with `Display` where a message was read from the `String`.
