# `zaino-primitives`: zatoshi quantities are librustzcash's `Zatoshis` and `ZatBalance`

Values are `zcash_protocol::value::Zatoshis` (an amount, `0 ..= MAX_MONEY`) and value balances `zcash_protocol::value::ZatBalance` (`-MAX_MONEY ..= MAX_MONEY`). zaino-primitives' own `Zatoshis`, `SignedZatoshis`, `ZatoshisOverflow` and `SignedZatoshisOverflow` are removed. `zaino-source`'s `DecodeError::OutputValue` and `DecodeError::ValueBalance` are removed (librustzcash's parser range-checks both).

**Migration:** `Zatoshis::new` → `Zatoshis::from_u64`, `as_u64` → `into_u64`, `checked_add` → `+` (an `Option`), `sum_balances` → `.sum::<Option<Zatoshis>>()`, `MAX` → `MAX_MONEY`; `SignedZatoshis::new` → `ZatBalance::from_i64`.
